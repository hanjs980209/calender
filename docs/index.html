Windows 10/11 · 로컬 메모와 선택적인 Google Calendar 연결

하루를 기록하는 바탕화면 달력

하루 달력(haru calender)은 날짜별 메모와 Google 일정을 확인하는 Windows 데스크톱 앱입니다. 로컬 기능은 계정 없이 사용할 수 있습니다.

주요 기능

  • 월간 달력, 날짜별 메모와 완료 체크, 색상 표시
  • Google 기본 캘린더의 일정 조회·등록·수정·삭제
  • 기존 메모를 Google 일정으로 복사하고 다른 PC에서 같은 계정으로 일정 확인
  • 배경 불투명도, 트레이 숨기기·복원, 로컬 메모 JSON 백업

Windows 앱 다운로드

Google 데이터 사용

사용자가 Google 계정을 연결하면 calendar.events 권한으로 기본 캘린더의 일정을 조회하고, 사용자가 요청한 등록·수정·삭제를 수행합니다. 앱은 PC에서 Google API에 직접 요청하며 별도 앱 운영 서버에 일정을 저장하지 않습니다. 인증 토큰은 운영체제 저장소로 암호화해 해당 PC에 저장합니다.

로컬 메모는 사용자가 복사·저장 버튼을 누를 때 Google 일정으로 등록됩니다. ChatGPT에서 조회하려면 사용 가능한 ChatGPT Google Calendar 연결을 별도로 설정해야 합니다.

이 버전의 실제 Windows 화면 동작과 개인 Google 계정의 OAuth 연결은 아직 검증되지 않았습니다. Google Cloud OAuth 설정은 연결 안내를 참조하세요.

개인정보처리방침과 이용약관을 확인해 주세요.
