달력과 MY DAY의 너비를 직접 조절하고, 개인·공유 캘린더를 색상으로 구분할 수 있게 했습니다.

## 다운로드와 교체

`haru-calendar-google-0.2.5-windows-x64.zip`을 내려받아 기존 앱을 종료하고 새 폴더에 전체 압축 해제한 뒤 `하루 달력.exe`를 실행하세요. 같은 Windows 사용자의 기존 메모·배경·Google 계정 설정은 유지됩니다. 자동 실행을 사용했다면 새 앱에서 옵션을 다시 켜 등록 경로를 갱신하세요. v0.2.4와 같은 Google 권한을 사용하므로 이번 변경만으로 재인증할 필요는 없습니다.

## 너비와 글자 조절

- 고정 2배 글자를 제거하고 기본 폭에서 원래 크기로 복원했습니다.
- 달력과 MY DAY 사이의 선을 드래그하면 두 영역의 가로 폭이 함께 조절됩니다.
- MY DAY를 넓히면 글자가 비례해 커지고 줄이면 작아집니다. 가독성을 위해 원래 크기부터 최대 2배까지 조절하며 달력의 최소 폭을 보호합니다.
- 프로그램 창 전체의 크기를 바꿀 때도 저장한 폭 비율에 맞춰 조절합니다. 우측 내용이 길면 세로로 스크롤할 수 있습니다.
- 구분선을 더블클릭하거나 포커스 후 Enter를 누르면 기본 폭으로 복원합니다. 좌우 방향키·Shift+방향키로도 조절할 수 있습니다.
- 마지막 비율은 로컬 설정에 저장합니다.

## 캘린더별 색상과 개인 일정 강조

- 개인 기본 캘린더와 공유 캘린더마다 서로 다른 기본 표시 색상을 적용합니다.
- 설정 → 표시할 Google 캘린더에서 각 캘린더 옆 색상 버튼으로 원하는 색을 지정할 수 있습니다.
- 내 기본 캘린더의 일정은 월간 칸과 MY DAY에서 먼저 표시하고, 굵은 글씨와 더 진한 배경·테두리 및 ‘내 캘린더’ 표시로 강조합니다. 각 그룹 내 시간 순서는 유지합니다.
- 표시 선택을 바꿔도 색상은 유지됩니다. 이 설정은 해당 PC의 앱 표시만 바꾸며 Google Calendar 원본을 수정하지 않습니다.

## 검증 범위

폭 경계·드래그·창 크기 변화·글자 연동·저장 복원·줄맞춤·키보드·개인 일정 우선순위·색상 선택/유지 등을 단위 및 브라우저 모의 API/IPC로 검증합니다. 릴리스는 빌드된 Windows 실행 파일의 시작, 메모·색상·분할 비율 저장, 실제 창 크기 변화와 자동 실행 등록·해제 검증을 통과해야 게시됩니다. 실제 개인 Google 계정의 동작과 PC 재부팅은 별도 확인 사항이며, 과거 신고된 Windows 종료·부팅 지연과 앱의 인과관계는 여전히 미확인입니다.
