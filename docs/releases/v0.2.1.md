Windows 10/11용 하루 달력의 시작 오류 수정 버전입니다.

## 다운로드와 교체

Assets에서 `haru-calendar-google-0.2.1-windows-x64.zip`을 내려받아 **새 폴더에 전체 압축 해제**한 뒤 `하루 달력.exe`를 실행하세요. DLL과 리소스를 함께 유지해야 합니다. 기존 v0.2.0 실행 파일은 종료하고 다시 사용하지 마세요.

기존 로컬 메모와 Google 로그인 정보는 같은 Windows 사용자의 앱 데이터 폴더를 사용하므로 유지됩니다. 교체 전 필요하면 `%APPDATA%/desktop-calendar-widget/calendar.json`을 별도로 복사해 메모를 보관하세요. 자동 시작을 사용했다면 Windows 설정에서 이전 경로의 시작 항목을 해제한 후 새 실행 경로를 확인하세요.

## 수정 내용

- `TypeError: win.moveBottom is not a function`을 일으키는 지원되지 않는 API 호출을 제거했습니다.
- 초기 창 표시에 지원되는 `showInactive()`를 사용하며, 잘못된 뒤로 보내기 메뉴와 IPC를 제거했습니다.
- 손상된 트레이 아이콘을 교체했습니다.
- 앱 오류 시 개인정보를 제외한 최소 기술 로그를 `diagnostics.jsonl`에 기록하고 앱을 종료하도록 했습니다.
- 릴리스 전에 실제 빌드한 Windows 실행 파일을 별도 프로필로 시작해 달력 표시·메모 저장과 복원·창 숨김/표시를 확인하도록 검증 단계를 추가했습니다.

## 검증 범위와 남은 제한

원본의 JavaScript 오류는 격리된 Windows CI에서 재현했으며 수정 소스의 시작을 확인했습니다. 이 릴리스는 단위 테스트와 빌드된 Windows 실행 파일의 시작 검증이 성공해야 게시됩니다. SHA256SUMS.txt로 다운로드 무결성을 확인할 수 있습니다.

이 검증은 모든 PC의 그래픽 드라이버·하드웨어에 대한 보장이 아닙니다. 앞서 보고된 Windows 강제 종료 및 부팅 지연과 앱의 인과관계는 확인되지 않았습니다. PC가 여전히 불안정하다면 앱 실행보다 Windows 점검을 우선하세요. 실제 사용자 Google 계정의 OAuth 연결, 코드 서명 및 바탕화면 영구 부착 기능은 이 릴리스에서 추가 검증·제공하지 않습니다.
