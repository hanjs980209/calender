Windows 10/11용 하루 달력에 자동 실행 설정과 배경 색상환을 추가했습니다.

## 다운로드와 사용

Assets에서 `haru-calendar-google-0.2.2-windows-x64.zip`을 다운로드하세요. 기존 앱을 완전히 종료하고 **계속 사용할 새 폴더에 전체 압축 해제**한 뒤 `하루 달력.exe`를 실행하세요. DLL과 리소스 파일을 함께 유지해야 합니다. 같은 Windows 사용자로 실행하면 기존 로컬 메모와 Google 로그인 정보를 계속 사용합니다.

- **⚙ 설정 → Windows 로그인 시 자동 실행**을 켜면 다음 로그인부터 달력이 열립니다. 기본값은 꺼짐입니다. 새 폴더로 옮겼다면 새 실행 파일에서 다시 켜 실행 경로를 갱신하세요. 끄면 자동 실행 등록이 해제됩니다. 같은 옵션을 트레이에서도 조절할 수 있습니다.
- **⚙ 설정 → 배경 색상**에서 색상환으로 색조·채도, 슬라이더로 밝기를 조절하세요. HEX 코드 입력과 기본 색상 복원도 지원합니다. 선택한 색과 불투명도는 다음 실행에도 유지됩니다.

## 검증

단위 테스트, 브라우저 색상환·설정 기능 검증을 수행했습니다. 이 릴리스는 빌드된 Windows 실행 파일의 시작, 메모·색상 저장 및 복원, 실제 Windows 로그인 항목 등록·해제 및 이전 실행 경로 갱신 검증을 통과해야 게시됩니다. CI에서 PC 재부팅이나 로그인 자체를 수행하는 검증은 포함되지 않습니다. SHA256SUMS.txt로 ZIP 무결성을 확인할 수 있습니다.

v0.2.1의 시작 오류 수정과 최소 오류 진단 로그를 포함합니다. 이전에 신고된 Windows 강제 종료·부팅 지연과 앱의 인과관계는 여전히 확인되지 않았으며, 모든 PC의 드라이버·하드웨어 동작을 보장하는 검증은 아닙니다. 실제 사용자 Google OAuth 연결과 코드 서명은 별도 사항입니다.
