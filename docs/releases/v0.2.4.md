개인·공유 Google 캘린더 표시와 오른쪽 글자 크기 확대를 추가했습니다.

## 다운로드

`haru-calendar-google-0.2.4-windows-x64.zip`을 내려받아 기존 앱을 종료하고 새 폴더에 전체 압축 해제한 뒤 `하루 달력.exe`를 실행하세요. Google OAuth 클라이언트 JSON을 새로 만들 필요는 없습니다. 기존 메모·배경 설정은 같은 Windows 계정에서 유지됩니다. 자동 실행을 사용했다면 새 앱에서 옵션을 다시 켜 경로를 갱신하세요.

## 공유 캘린더 설정

1. Google Cloud → Google Auth Platform → 데이터 액세스에 기존 `https://www.googleapis.com/auth/calendar.events`와 함께 **`https://www.googleapis.com/auth/calendar.calendarlist.readonly`** 범위를 추가하세요.
2. 하루 달력 설정에서 **공유 캘린더 권한 추가** 또는 **Google 로그인**으로 다시 로그인하고 두 권한을 허용하세요. 기본 일정만 보던 기존 토큰은 추가 로그인 전까지 기본 캘린더를 계속 표시합니다.
3. **표시할 Google 캘린더**에서 볼 캘린더를 체크하세요. 읽기 권한이 있는 개인·공유 캘린더를 최대 20개까지 함께 볼 수 있습니다.
4. **새 일정을 저장할 캘린더**에서 쓰기 가능한 캘린더를 선택하세요. 일정마다 출처를 표시하며 수정·삭제는 원래 캘린더에 반영합니다. 읽기 전용 공유 일정은 수정·삭제할 수 없습니다.

목록에 없으면 Google Calendar 웹에서 해당 계정에 공유 초대를 수락·추가한 뒤 앱의 ‘지금 새로고침’을 누르세요. 바쁨/한가함만 볼 수 있는 공유는 일정 세부 정보 조회 권한이 필요합니다. 계정 변경 시 이전 계정의 캘린더 선택을 초기화합니다.

시간대가 다른 캘린더를 함께 볼 때 날짜 문자열이 아닌 실제 시각으로 일정을 정렬합니다.

## 글자 크기

오른쪽 선택 날짜를 22→44px, 일정 제목·메모를 12→24px, 일정 시간을 10→20px로 확대했습니다. 입력창·관련 버튼도 확대했고 사이드바 폭과 줄바꿈을 조정했습니다. 일정이 많으면 오른쪽 영역을 스크롤할 수 있습니다. 월간 달력 칸의 글자 크기는 유지됩니다.

## 검증 범위

캘린더 목록 페이지 처리, 권한, 여러 캘린더의 동일 일정 ID 구분, 저장 대상, 선택 보존, 기존 권한 호환성은 모의 Google API/IPC로 검증합니다. 릴리스는 단위 테스트와 실제 Windows 패키지의 시작·메모·색상·자동 실행 등록·해제·글자 크기 검증을 통과해야 게시됩니다. 실제 개인 계정과 공유 캘린더의 OAuth 연결은 사용자 권한 허용 후 확인이 필요합니다. 새 범위에 대해 Google이 추가 검증을 요구할 수 있습니다. 기존 시스템 종료·부팅 지연 신고와의 인과관계는 미확인이며 실제 PC 재부팅 검증은 포함하지 않습니다.
