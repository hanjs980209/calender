이 방침은 hanjs980209/calender에서 제공하는 하루 달력 Windows 앱과 앱 소개 사이트에 적용됩니다.

처리하는 정보와 목적

앱은 사용자가 입력한 날짜별 메모, 완료 상태, 색상 및 표시 설정을 해당 PC에 저장합니다. Google Calendar 연결을 선택한 경우 인증 토큰과 OAuth 클라이언트 설정을 저장하며, 일정 표시와 사용자가 요청한 일정 생성·변경·삭제를 위해 제목, 내용, 날짜, 시간, 일정 ID 등의 Google 일정 정보를 처리합니다.

저장 및 전송

로컬 메모와 설정은 PC의 Electron 사용자 데이터 폴더에 저장합니다. Google 인증 정보는 운영체제의 safeStorage로 암호화해 별도 파일에 저장하며 Windows에서는 DPAPI를 사용합니다. 조회한 Google 일정은 앱 실행 중 메모리에서 처리합니다. 사용자가 저장한 Google 일정은 Google 계정에 보관됩니다. JSON 백업에는 로컬 메모와 설정이 포함되며 Google 인증 토큰은 포함되지 않습니다.

Google 로그인과 API 요청은 PC와 Google 사이에서 이루어집니다. 앱 운영자가 별도의 서버로 일정이나 메모를 수집하지 않습니다. 사용자가 별도 백업 파일이나 OAuth JSON 원본을 보관한 경우 해당 파일의 관리 책임은 사용자에게 있습니다.

제공·판매 및 분석

앱은 사용자 데이터를 광고 목적으로 사용하거나 판매하지 않으며, 자체 분석·추적 기능을 포함하지 않습니다. Google API 데이터는 앱의 사용자 대면 일정 기능을 제공하는 용도로만 사용하며, 일반 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 전송은 Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

연결 해제와 삭제

앱 설정의 연결 해제는 해당 PC에 저장된 Google 토큰을 삭제하며 Google의 일정은 삭제하지 않습니다. Google 계정의 타사 앱 연결 설정에서 접근 권한을 철회할 수 있습니다. Google 일정 삭제는 앱의 일정 삭제 기능 또는 Google Calendar에서 수행하세요. 로컬 메모 및 설정은 앱을 종료하고 사용자 데이터 폴더의 calendar.json을 삭제할 수 있습니다. Windows 기본 사용자 데이터 위치는 보통 %APPDATA%/desktop-calendar-widget/입니다. 별도 백업 파일과 다운로드한 OAuth JSON은 직접 삭제해야 합니다.

소개 사이트 및 외부 서비스

소개 사이트는 Google 인증 토큰이나 일정을 입력받지 않습니다. GitHub Pages에 배포하는 경우 호스팅 제공자 GitHub가 접속 관련 기술 정보를 처리할 수 있으며 GitHub 개인정보처리방침이 적용됩니다. Google 계정의 데이터 처리는 Google 개인정보처리방침을 확인하세요. ChatGPT를 별도로 연결하는 경우 그 서비스의 정책이 적용됩니다.

문의 및 변경

개인정보 관련 문의는 운영 저장소의 Issues로 남길 수 있습니다. 공개 문의에 일정 내용, 인증 토큰, OAuth JSON 등 개인정보를 첨부하지 마세요. 기능과 데이터 처리 변경 시 이 페이지를 갱신합니다.
