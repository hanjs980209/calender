# v0.2.0 Windows 실행 오류 조사

2026-11-02 사용자 신고: 앱 실행 시 `TypeError: win.moveBottom is not a function` 메인 프로세스 오류 표시. 비슷한 시점에 Windows 강제 종료와 부팅 지연이 있었으며 이후 부팅 가능 상태로 돌아옴. 시스템 오류 코드와 Windows 이벤트/덤프는 아직 미확보.

## 확인된 사실

- 공개 v0.2.0 Windows ZIP의 SHA-256이 릴리스의 SHA256SUMS.txt와 일치함.
- ZIP 무결성 검사 통과. ASAR 내부의 모든 앱 소스는 Windows CRLF를 LF로 정규화했을 때 CI 빌드 커밋 858390c와 일치함. 이는 배포 소스의 일치 확인이며 OS 수준 원인 규명이나 악성코드 검사를 뜻하지 않음.
- ready-to-show 이벤트에서 지원되지 않는 `BrowserWindow.moveBottom()`을 호출함. 동일한 호출이 트레이 메뉴와 IPC에도 존재함. 사용자 오류 스택과 직접 일치하는 앱 결함.
- 내장 트레이 PNG의 IDAT CRC가 일치하지 않고 zlib 스트림이 잘려 있음. 사용자 보고의 TypeError와는 별개의 자산 결함.
- 앱에는 시스템 종료·재부팅 명령, 셸 명령 실행, 드라이버 설치, 관리자 권한 요청, 부팅 설정 변경 코드가 없음. Node 파일 쓰기는 사용자 데이터, 사용자가 선택한 백업 파일에 한정됨.
- 로그인 자동 시작 설정은 트레이 메뉴의 사용자 클릭 시 `app.setLoginItemSettings`로 변경됨. 기본 실행 시 자동 시작을 등록하지 않음.
- 앱은 Electron/Chromium의 기본 그래픽 가속을 사용함. 코드 검색만으로 드라이버·GPU·하드웨어 문제나 OS 오류와의 관계를 배제할 수 없음.

## 수정과 검증

- 잘못된 API와 뒤로 보내기 메뉴/IPC를 제거하고 `show:false` + `showInactive()`로 시작 시 표시함.
- 유효한 PNG 자산으로 트레이 아이콘 교체.
- 처리되지 않은 앱 오류, 렌더러/자식 프로세스 종료의 최소 기술 로그 추가. 치명적 오류 시 앱만 종료. 개인정보나 토큰을 로그에 기록하지 않음.
- 네이티브 시작 검증: 독립 임시 userData, 원본 빌드 소스와 수정 소스를 Windows CI에서 비교. 기본 렌더링 설정으로 시작하며 사용자 PC에서는 재현을 요청하지 않음.
- 소스 수정과 기존 릴리스 ZIP 교체는 별도 단계. 이 변경으로 v0.2.0 릴리스가 교체되지는 않음.

## 아직 필요한 증거

같은 시각의 신뢰성 모니터 및 이벤트 뷰어 기록. BugCheck/Windows 오류 보고의 중지 코드와 문제 모듈, LiveKernelEvent, Display 기록, 종료 요청 기록(User32 1074) 등을 구분해야 함. Kernel-Power 41과 EventLog 6008은 비정상 종료 사실을 나타낼 수 있으나 그 자체로 앱이 원인임을 입증하지 않음. 사용자에게 전체 메모리 덤프나 Google 인증 파일을 공개 업로드하도록 요청하지 않음.

## Windows CI 비교 결과

[검증 실행 41366586962](https://github.com/hanjs980209/calender/actions/runs/41366586962), 수정 커밋 8bd863e.

- 원본 소스: exit 1. `TRAY_ICON_EMPTY=true`, `FAIL: native application startup: win.moveBottom is not a function`. 사용자 오류를 격리된 Windows 환경에서 재현함.
- 수정 소스: exit 0. `TRAY_ICON_EMPTY=false`. 네이티브 창·preload IPC·로컬 메모 초기화와 달력 42칸 표시 후 3초 동안 유지 검증 통과. stderr 없음.
- 최초 CI 시도는 개발용 Electron 실행 파일이 아직 설치되지 않아 앱 시작 자체가 실행되지 않았음. Electron 43의 공식 `require('electron')` 진입점으로 개발 런타임을 설치한 뒤 위 비교를 수행함. 이 환경 준비 실패와 앱 시작 결과를 구분함.
- 단위 테스트 13개, 브라우저 기능 검증과 모의 IPC Google UI 검증 통과.
- 사용자는 신뢰성 모니터에서 관련 이벤트를 찾지 못했다고 보고함. Windows 종료 원인이 없다는 의미로 해석하지 않음. OS 종료·부팅 지연과 앱의 인과관계는 여전히 미확인.

현재 수정은 GitHub 소스에 반영되었고 v0.2.0 공개 ZIP은 교체하지 않았음. 사용자에게 기존 버전을 다시 실행해 재현하도록 요청하지 않음.
