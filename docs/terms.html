기능과 사용 범위

하루 달력은 Windows에서 로컬 메모와 Google Calendar의 기본 캘린더 일정을 표시·관리하는 앱입니다. Google 기능은 사용자가 자신의 계정으로 로그인하고 접근 권한을 허용한 경우 사용할 수 있습니다. 앱의 로컬 메모와 Google 일정은 별도 데이터입니다.

사용자의 확인과 관리

Google 일정 등록·수정·삭제는 실제 계정과 다른 기기에도 반영될 수 있습니다. 사용자는 저장·삭제 전에 대상과 내용을 확인하고 중요한 메모와 일정을 별도 백업해야 합니다. 로그인·인증 설정 파일과 백업 파일은 사용자가 안전하게 보관해야 합니다.

제공 상태

현재 앱은 개발 초기 버전이며 실제 Windows 화면 동작과 개인 Google 계정 연결의 모든 조합을 검증하지 않았습니다. 코드 서명과 영구적인 Windows 바탕화면 부착 기능은 포함되어 있지 않습니다. 오류·중단·데이터 손실이 없음을 보장하지 않습니다.

외부 서비스

Google 기능의 이용은 Google의 서비스 조건, API 정책, 권한 및 네트워크 상태에 영향을 받습니다. Google의 정책에 따라 인증 재진행이 필요할 수 있습니다. ChatGPT에서 일정 조회는 별도의 연결과 해당 서비스의 기능 제공 여부에 따릅니다.

종료와 변경

사용자는 앱을 종료하거나 Google 연결을 해제할 수 있습니다. 데이터 보관과 삭제 방법은 개인정보처리방침을 참조하세요. 기능이나 이용 조건이 변경되면 이 페이지와 저장소를 통해 안내합니다.
