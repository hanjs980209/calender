# 하루 달력

Windows 10/11용 투명 바탕화면 달력 위젯입니다. Electron 기반이며 로컬 메모와 선택적인 Google Calendar 연동을 제공합니다.

## 기능

- Google Calendar 로그인, 개인·공유 캘린더 다중 표시, 권한에 따른 일정 등록·수정·삭제, 기존 메모 복사
- 오른쪽 날짜·Google 일정·메모 글자 크기 2배 확대
- 월간 달력, 오늘로 이동, 이전/다음 달 및 키보드 방향키 탐색
- 날짜별 메모, 완료 체크, 네 가지 색상, 삭제 확인
- 배경 색상환(색조·채도), 밝기·HEX 입력, 불투명도, 월요일 시작 설정
- JSON 백업 내보내기/가져오기 (덮어쓰기 확인)
- 프레임 없는 창 이동·크기 조절, 트레이 숨기기/복원/종료
- 설정 화면과 트레이의 Windows 로그인 시 자동 실행 켜기·끄기

## Windows에서 실행

Node.js 22 이상을 설치한 뒤 저장소 폴더에서 실행합니다.

```powershell
npm ci
npm start
```

설치 파일 만들기:

```powershell
npm run dist:win
```

`dist/`에 생성된 설치 프로그램을 실행하세요. 배포용 코드 서명 인증서는 포함되어 있지 않습니다.

## 사용 방법

날짜를 선택하고 오른쪽에 메모를 입력한 뒤 추가하세요. 날짜를 더블클릭하면 입력창으로 이동합니다. 상단을 드래그하면 이동하고 창 가장자리에서 크기를 조절할 수 있습니다. `−` 버튼은 창을 트레이로 숨깁니다. 트레이 아이콘을 더블클릭하거나 메뉴에서 달력을 다시 여세요. 앱 종료는 트레이 메뉴에서 가능합니다.

이 버전은 일반 투명 데스크톱 창입니다. 실행 시 다른 앱의 키보드 포커스를 가져오지 않고 표시합니다. Windows Explorer의 바탕화면 계층(WorkerW)에 영구 부착하는 기능과 Win+D 이후 자동 복원은 구현하지 않았습니다. 바탕화면 아이콘과의 겹침을 피해 창을 배치하세요.

메모와 설정은 Electron 사용자 데이터 폴더의 `calendar.json`에 저장합니다. Windows에서는 일반적으로 `%APPDATA%/desktop-calendar-widget/`입니다. 앱 업데이트/재실행 시 유지됩니다. 로컬 메모는 PC별로 저장되며 Google에 등록한 일정은 다른 PC에서 같은 Google 계정으로 연결해 확인할 수 있습니다. 백업 기능으로 로컬 메모를 별도 보관하세요.

## 개발 및 검증

```sh
npm test
npm run preview
# 다른 터미널에서
node test/smoke.cjs
node test/google-ui-smoke.cjs
```

브라우저 미리보기는 로컬 스토리지를 사용하며 트레이와 창 제어는 Windows 앱에서만 동작합니다. UI 검증은 `CHROMIUM_PATH` 또는 `/usr/bin/chromium`을 사용합니다. Windows 설치·트레이·자동 시작·창 배치는 실제 Windows에서 별도 검증해야 합니다.

실제 메모는 기본적으로 비어 있습니다. 로컬 기능에는 계정이나 API 키가 필요하지 않습니다. Google 기능은 데스크톱 OAuth 클라이언트 설정과 로그인이 필요합니다. [Google Calendar 연결 안내](docs/GOOGLE_CALENDAR.md)를 따르세요.

## 클라우드에서 생성한 실행 패키지

`dist/haru-calendar-google-0.2.3-windows-x64.zip`을 Windows에서 전체 압축 해제한 뒤 `하루 달력.exe`를 실행하세요. 함께 들어 있는 리소스와 DLL을 유지해야 합니다. Windows용 패키징과 ZIP 무결성은 확인했으며, Windows에서의 실제 실행은 아직 검증하지 않았습니다. 이 클라우드 환경에는 Wine이 없어 NSIS 설치 파일 생성은 완료하지 못했습니다. 위 `npm run dist:win` 명령은 Windows에서 실행하세요.

## v0.2.0 시작 오류 조사 (2026-11-02)

v0.2.0의 `win.moveBottom()` 호출은 Electron에 없는 메서드이며, 사용자가 보고한 메인 프로세스 JavaScript 오류의 원인입니다. 소스에서는 해당 호출과 관련 메뉴를 제거하고 지원되는 `showInactive()`로 초기 표시를 변경했습니다. 손상된 트레이 PNG도 교체했습니다. 이 수정은 v0.2.1에 포함됩니다. 기존 v0.2.0 다운로드 ZIP은 교체하지 않았습니다.

시스템 강제 종료 및 부팅 지연과의 인과관계는 확인되지 않았습니다. v0.2.0을 다시 실행해 재현하지 말고 Windows 기록부터 확인하세요. 트레이에서 ‘로그인 시 시작’을 켰던 경우 Windows 설정의 앱 → 시작 프로그램에서 하루 달력을 끌 수 있습니다. 복구나 포맷 전에 중요한 데이터를 보존하세요.

수정 소스는 앱 오류 시 `diagnostics.jsonl`에 고정 이벤트명, 런타임 버전, 종료 코드를 기록하고 앱만 종료합니다. 오류 메시지·일정·OAuth 토큰·인증 요청 URL은 로그에 기록하지 않습니다. 네이티브 시작 검증은 격리된 Windows CI에서 수행하며 실제 PC의 드라이버 문제를 배제하는 검사는 아닙니다.

최신 수정 버전의 변경·교체 방법은 [v0.2.1 안내](docs/releases/v0.2.1.md)를 확인하세요.

## 자동 실행과 배경 색상 (v0.2.2)

설정에서 **Windows 로그인 시 자동 실행**을 켜면 현재 Windows 계정으로 로그인한 뒤 달력이 표시됩니다. 기본값은 꺼짐이며 Windows 로그인 전에 서비스로 실행하지 않습니다. 압축을 푼 폴더를 계속 사용할 위치에 놓고 켜세요. 새 폴더로 옮기거나 새 버전을 받은 경우 새 실행 파일에서 다시 켜 등록 경로를 갱신하세요. 끄면 등록이 해제됩니다. Windows가 시작 항목을 사용 중지한 경우도 설정에 표시합니다.

설정의 **배경 색상**에서 색상환을 드래그하거나 밝기·HEX 코드를 조절하세요. 색상환은 좌우 방향키로 색조, 위아래로 채도를 조절할 수 있습니다. 색상과 투명도는 로컬 메모와 함께 저장되며 자동 실행 설정은 Windows의 PC별 시작 설정으로 관리합니다. [v0.2.2 변경 안내](docs/releases/v0.2.2.md)를 확인하세요.

## 공유 캘린더 (v0.2.3)

Google Cloud의 데이터 액세스에 `https://www.googleapis.com/auth/calendar.calendarlist.readonly`를 기존 `calendar.events`와 함께 추가하세요. 앱 설정에서 **공유 캘린더 권한 추가**로 한 번 다시 로그인한 뒤 **표시할 Google 캘린더**를 체크하세요. 계정의 등록된 캘린더 중 일정 세부 정보 읽기 권한이 있는 캘린더를 최대 20개까지 함께 표시합니다. 기본 선택은 내 기본 캘린더이며, 선택 내용은 이 PC에 저장됩니다. **새 일정을 저장할 캘린더**에서 쓰기 가능한 대상을 선택하세요. 읽기 전용 공유 일정은 수정·삭제하지 못하며 일정마다 출처를 표시합니다. 공유가 새로 추가되었다면 ‘지금 새로고침’으로 목록을 갱신하세요.

[공유 캘린더 및 글자 크기 확대 변경 안내](docs/releases/v0.2.3.md)를 확인하세요.
